# Billboard

One page that shows Ben what needs him across every Claude Code session, on his phone:

- **Needs you:** open questions from any session, archived or not.
- **Try it:** what shipped or was mocked that only Ben can check, and things only he can do.
- **Running:** what each working session is doing.
- **Shipped:** merged PRs across his repos, by day.

It's being designed in the "Billboard Mocks" artifact: https://claude.ai/artifact/UbyQP4gmaWyhihaCU8i1S9. Nothing is built yet.

The original Billboard, a Kanban board app (React, Express, MongoDB), is kept at the tag `kanban-v1`.
